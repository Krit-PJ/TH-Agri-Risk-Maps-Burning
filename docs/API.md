# TH Agri-Risk Map Burning — Public Data API v1.2

API อ่านอย่างเดียวสำหรับระบบอื่นที่ต้องการนำข้อมูลจุดความร้อนและระดับความเสี่ยงไปใช้ ข้อมูลเป็นปัจจุบันเสมอ
แคชจะถูกล้างทันทีเมื่อมีการนำเข้า เปิด/ปิดชุดข้อมูล หรือเปลี่ยนการตั้งค่า

**Base URL**

```
https://script.google.com/macros/s/AKfycbzAgSOxgQsaOx9bqBYM53KXFzk1QKsop46HZeINgtUzLXkaZTYYaZH3RZu0l-HDlN8TKA/exec?action=api
```

* วิธีเรียก: `GET` เท่านั้น เรียกจากเบราว์เซอร์ (fetch, CORS), Excel / Power Query, Google Sheets `IMPORTDATA()`, Python, R ได้
* รูปแบบ: `format=json` (ค่าเริ่มต้น) หรือ `format=csv` (UTF-8 พร้อม BOM เปิดใน Excel ได้ทันที)
* วันที่: `YYYY-MM-DD` เวลาไทย · ฤดูกาลเผา: 1 ต.ค. – 30 ก.ย. ตั้งชื่อตามปี พ.ศ. ที่สิ้นสุด (เช่น ฤดู 2570 = 1 ต.ค. 2569 – 30 ก.ย. 2570)
* รหัสพื้นที่: จังหวัด 2 หลัก · อำเภอ 4 หลัก · ตำบล 6 หลัก (รหัสกรมการปกครอง)

## Endpoints

| fn | พารามิเตอร์ | คืนค่า |
|---|---|---|
| `meta` | – | เวอร์ชัน API, สูตรที่ใช้งานอยู่ (`abri`: เวอร์ชัน จุดตัด เกณฑ์ขั้นต่ำ ปีงบที่ประเมิน · `model5`), ช่วงข้อมูล, เดือนที่มีข้อมูล (`dataMonths`), นโยบายดาวเทียม, ประเภทพื้นที่, ระดับ, รายการ endpoint |

## fn=risk — สูตรและช่วงเวลา (v1.2)

* ค่าเริ่มต้นคือ **ABRI-2Y**: ปีงบที่ประเมิน Y (`assessmentYear`) = ปีงบถัดจากปีงบล่าสุดที่ครบแล้ว ณ `end` · ปีฐาน (`baseYears`) = Y−2, Y−1 · จัดลำดับภายในจังหวัด จุดตัด 50/75/90 · จุดรวม < 3 = ต่ำ — **ไม่ใช่การทำนาย**
* ไม่ระบุ `end` = ปีงบประมาณล่าสุดที่ครบแล้ว (ค่าเริ่มต้นเดียวกับหน้าเว็บ)
* `model=M5` (ความหนาแน่น + การเผาซ้ำ) และ `model=M4` (เกณฑ์กลาง NASA FIRMS) ยังให้บริการ · Model 3 / Model 1 ยกเลิกแล้ว
* ดาวเทียม: NOAA-20 ตั้งแต่วันแรกที่มีข้อมูลของจังหวัด ก่อนหน้านั้น Suomi-NPP (`meta.satellitePolicy`)

## fn=risk — คอลัมน์

ทุกผู้ใช้:

| คอลัมน์ | ความหมาย |
|---|---|
| `code`, `name` | รหัส/ชื่อตำบล (หรืออำเภอเมื่อ `level=district`) |
| `districtCode`, `district` | รหัส/ชื่ออำเภอ |
| `levelIndex`, `level` | 0 ต่ำ · 1 ปานกลาง · 2 สูง · 3 สูงมาก · −1 ไม่ประเมิน (ไม่มีพื้นที่เกษตร) |
| `hs0` | จำนวนจุดความร้อนฤดูปัจจุบันตั้งแต่ 1 ต.ค. ถึงวันข้อมูลล่าสุด (สัญญาณเฝ้าระวัง) |

เพิ่มเมื่อส่ง `key` ที่ได้รับจากผู้ดูแลระบบ — ABRI-2Y:

| คอลัมน์ | ความหมาย |
|---|---|
| `score` | ABRI: เปอร์เซ็นไทล์ 0–100 ภายในจังหวัด (0 = ต่ำกว่าเกณฑ์ขั้นต่ำ) |
| `n2y`, `n1`, `n2` | จุดรวม 2 ปีฐาน, ปีฐาน Y−1, ปีฐาน Y−2 |
| `hs0` | จุดปีงบที่ประเมิน (เฝ้าระวัง ไม่คิดคะแนน) |
| `crop` | ชนิดพืชหลัก 2 อันดับแรก |
| `density` | จุดต่อปีต่อ 1,000 ไร่พื้นที่เพาะปลูก (ข้อมูลประกอบ) |
| `reason` | เหตุผลของระดับ |
| `nHigh`, `nTambon` | (ระดับอำเภอ) ตำบลระดับสูง–สูงมาก / จำนวนตำบล |

Model 5 (`model=M5`):

| คอลัมน์ | ความหมาย |
|---|---|
| `score` | ลำดับเปอร์เซ็นไทล์ 0–100 ภายในจังหวัด (0.7·ความหนาแน่น + 0.3·การเผาซ้ำ) ≥ 90 สูงมาก · ≥ 75 สูง · ≥ 50 ปานกลาง |
| `D` | จุดความร้อนเฉลี่ยต่อปีต่อ 1,000 ไร่พื้นที่เพาะปลูก (ปีฐาน เดือนที่ใช้) |
| `R` | % ของจุดที่อยู่ในกริด 1 กม. ที่พบจุด ≥ 2 ปีฐาน |
| `cropRai` | พื้นที่เพาะปลูก (ไร่) ESA WorldCover 2021 |
| `n0`, `n1`, `n2` | จำนวนจุดของปีฐาน (ใหม่ → เก่า) เฉพาะเดือนที่ใช้ |
| `hs0` | จำนวนจุดทั้งปีงบของ `end` (ถึงวันสิ้นสุด) |
| `trend` | ปีล่าสุดเทียบค่าเฉลี่ยปีก่อน `up` / `down` / `flat` (ข้อมูลประกอบ ไม่คิดคะแนน) |
| `crop` | ชนิดพืช 2 อันดับแรกของจุด (ข้อมูลประกอบ) |
| `reason` | เหตุผลของระดับ |
| `nHigh`, `cropHigh`, `nTambon` | (ระดับอำเภอ) ตำบลระดับสูง–สูงมาก, พื้นที่เกษตรในตำบลเหล่านั้น, จำนวนตำบล |

Model 4 (`model=M4`):

| คอลัมน์ | ความหมาย |
|---|---|
| `score` | คะแนนจัดลำดับเฝ้าระวัง 0–100 (เปอร์เซ็นไทล์เทียบฐานกลาง) — **ไม่ใช่ความน่าจะเป็นการเผา** |
| `H` | หน่วยตรวจพบ (กริด 500 ม.–วัน) ต่อ 1,000 ไร่พื้นที่เพาะปลูกต่อฤดู หลังปรับ Empirical Bayes |
| `cropRai` | พื้นที่เพาะปลูก (ไร่) จาก ESA WorldCover 2021 |
| `u0`, `u1`, `u2` | หน่วยตรวจพบของฤดูฐาน (ใหม่ → เก่า) |
| `base`, `trend` | จุดช่วงเดียวกันฤดูก่อน และแนวโน้ม `up` / `down` / `flat` |
| `reason` | เหตุผลหลักของคะแนน (ข้อความ) |
| `nHigh`, `cropHigh`, `nTambon` | (ระดับอำเภอ) จำนวนตำบลคะแนนสูง–สูงมาก, พื้นที่เกษตรในตำบลเหล่านั้น, จำนวนตำบลทั้งหมด |

ส่วนหัว JSON บอก `model`, `modelVersion`, `season`, `history` (ฤดูฐาน), `end`, `latest`, `fallback` (ถ้าใช้ Model 3 แทน)
Model 4 ใช้กับ `land` = พื้นที่เกษตร / เขต สปก. ใน 17 จังหวัดที่มีข้อมูลพื้นที่เพาะปลูก ประเภทอื่นระบบใช้ Model 3 และแจ้งใน `fallback`
