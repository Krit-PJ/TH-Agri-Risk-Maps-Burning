# Thailand Agri-Risk Maps Burning V2

ระบบแผนที่ความเสี่ยงการเผาในพื้นที่การเกษตรของประเทศไทย ครอบคลุมขอบเขตจังหวัด อำเภอ และตำบล 77 จังหวัด พร้อมระบบลงทะเบียนผู้บันทึกข้อมูลและการจัดการ HS แบบกำหนดสิทธิ์รายจังหวัด

## เว็บไซต์

https://krit-pj.github.io/TH-Agri-Risk-Maps-Burning/

หน้าเลือกจังหวัดแสดงเฉพาะจังหวัดที่มีข้อมูล HS ในระบบ ปัจจุบันชุดข้อมูลที่เผยแพร่มีจังหวัดกำแพงเพชร ส่วนขอบเขตของทั้ง 77 จังหวัดติดตั้งไว้พร้อมเปิดใช้เมื่อมีข้อมูล HS ที่ผ่านการตรวจ

## สถาปัตยกรรม

- GitHub Pages: แผนที่และข้อมูลสาธารณะเท่านั้น
- Google Apps Script Web App: ลงทะเบียน รับทราบ PDPA เข้าสู่ระบบ อนุมัติ และจัดการข้อมูล
- Google Sheet: ฐานข้อมูลส่วนตัวสำหรับบัญชี คำขอ HS และ Audit Log
- Admin: ทำรายการได้เฉพาะจังหวัดที่ได้รับอนุมัติ
- Super Admin: อนุมัติบัญชีและจัดการทุกจังหวัด

หมายเลขโทรศัพท์และรหัสผ่านไม่อยู่ใน repository นี้ ค่าโทรศัพท์ที่ใช้ตรวจสิทธิ์เก็บเป็นแฮชแบบมี pepper ในฐานข้อมูลส่วนตัว
