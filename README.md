# TH-Agri-Risk-Maps-Burning

โค้ดรุ่น 2: บัญชีรายบุคคล คำขอ pending/อนุมัติ ขอบเขตจังหวัด–อำเภอ และ Google public HS feed

## การใช้งาน
แอปเต็มอยู่ใน `app/` ใช้ Node.js เรียก `node app/v2/server.cjs` บริการปัจจุบันออกแบบให้เปิดบนเครื่องที่ติดตั้ง ต้องใส่ชุดข้อมูลแผนที่ที่ตรวจสอบแล้วใน app/data ก่อนใช้ ข้อมูล HS และบัญชีจริงไม่อยู่ใน Repository นี้

เซิร์ฟเวอร์ใหม่ให้ตั้ง AGRI_STATE_DIR, AGRI_OWNER_USERNAME, AGRI_OWNER_PASSWORD ในสภาพแวดล้อมส่วนตัว แล้วรัน `node app/v2/bootstrap-owner.cjs` ก่อนเปิดบริการครั้งแรก ห้ามเผยแพร่ค่ารหัสผ่านหรือโฟลเดอร์สถานะ

รายละเอียดอยู่ใน [คู่มือรุ่นบัญชีและสิทธิ์](app/README_ACCESS_EDITION.md) หน้า GitHub Pages เป็นหน้าทางเข้าสาธารณะ ไม่มีบริการ Login/อนุมัติออนไลน์ ต้องจัดเตรียม Backend HTTPS และที่เก็บสถานะถาวรเพิ่มเติมก่อนเปิดบัญชีออนไลน์

Apps Script อยู่ใน app/cloud/apps-script อ่านเฉพาะแถวที่ published=TRUE ในชีตสาธารณะที่กำหนด ค่าเริ่มต้นไม่เผยแพร่จังหวัดใด ไม่ใช้แทนระบบบัญชีหรือรับข้อมูลลงทะเบียน
