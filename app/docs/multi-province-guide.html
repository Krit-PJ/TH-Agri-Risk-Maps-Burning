คู่มือ Agri-Risk Map Burning

กำลังโหลดจังหวัด…

แบบจำลองนี้เป็น default operational model สำหรับการเฝ้าระวัง ไม่ใช่มาตรฐานระดับประเทศ ต้องตรวจสอบความเหมาะสมของข้อมูลและพารามิเตอร์ก่อนใช้ในจังหวัดใหม่

บัญชีและสิทธิ์รุ่น 2

ลงทะเบียนบัญชีรายบุคคลและรับทราบประกาศการใช้ข้อมูลก่อนส่งคำขอ ผู้บันทึกและ Admin รออนุมัติก่อนใช้งาน Admin จัดการผู้บันทึกเฉพาะจังหวัดของตน ส่วน Super Admin จัดการได้ทุกจังหวัด ระบบตรวจสิทธิ์จากเซิร์ฟเวอร์ ไม่ใช้รหัสผ่านร่วมที่เผยแพร่ในคู่มือ

การใช้งาน

  1. ผู้ใช้ทั่วไปเลือกจังหวัดหลักก่อนแสดงข้อมูลที่อนุญาตเผยแพร่ บัญชีเจ้าหน้าที่โหลดแผนที่จังหวัดและอำเภอตามสิทธิ์จากเซิร์ฟเวอร์โดยอัตโนมัติ
  2. เลือกช่วงเดือน/ปี แล้วกดแสดงข้อมูล
  3. เลือกอำเภอและตำบลตามลำดับ รายชื่อมาจากขอบเขตจังหวัดที่เลือก
  4. ตรวจตารางเปรียบเทียบช่วงเดียวกันย้อนหลัง 1 ปี กราฟ และสีแผนที่
  5. กดพิมพ์รายงานเพื่อพิมพ์ A4; Admin นำเข้า 1 จังหวัด; Super Admin นำเข้าบางจังหวัดหรือครบ 77 จังหวัด แล้วเลือกพื้นที่จากชุดที่นำเข้า หรือนำเข้า Excel ได้

เกณฑ์ความเสี่ยง

เลือกชุดข้อมูลปีเดียว: ใช้ Annual Evidence Gate จำนวน Hotspot กำหนดช่วงระดับ ชนิดพืชและขนาดพื้นที่ปรับคะแนนภายในระดับ

เลือกหลายชุดปี: ใช้สูตรถ่วงน้ำหนักดังนี้

ระดับช่วงคะแนน

Hotspot Score ใช้จำนวนถ่วงน้ำหนักปีเทียบกับค่าสูงสุดอ้างอิงของขอบเขตที่เลือก; Trend ใช้ 2 ชุดปีล่าสุด; Crop ใช้ค่าเฉลี่ยคะแนนพืชของ HS; Area ใช้ log ของ AREA_RAI ที่ normalize ภายในขอบเขต การเลือกจังหวัดแสดงการแจกแจงคะแนนอำเภอ การเลือกอำเภอแสดงคะแนนตำบล ไม่มีการเพิ่มสูตรคะแนนรวมจังหวัดหรือ high-coverage rule

การนำเข้าและ QA

รองรับ YYYY-MM-DD หรือ Date, Time, Province, Amphoe, Tambon, LandType, PlantType, Latitude และ Longitude; hsID เป็นข้อมูลเสริม รองรับ Maps และพิกัด UTM X/Y แบบเดิม ชื่อไทย ชื่ออังกฤษ และรหัสจังหวัด normalize ตาม config

ระบบกรองจังหวัด → LandType → PlantType และรายงานจำนวนแต่ละขั้น วันที่/พิกัดผิด ข้อมูลซ้ำ รหัสขัดกับชื่อ ค่าที่ไม่รู้จัก และสรุปอำเภอ/ตำบล/เดือน/ปี ดาวน์โหลด QA ได้แม้ผลไม่ผ่านนำเข้า

ข้อมูลนำเข้าอยู่เฉพาะหน่วยความจำ ต้องดาวน์โหลด GeoJSON แล้วนำไปวางใน data path ที่กำหนดเอง ก่อนเปลี่ยนจังหวัดหรือปิดหน้าเว็บ ไม่มีการเขียนกลับ Drive หรือ GitHub

ข้อมูลและข้อจำกัด

จังหวัดที่ยังไม่มีขอบเขตหรือ HS จะแสดงสถานะไม่มีข้อมูลอย่างชัดเจน การไม่มี HS ไม่ใช่ข้อพิสูจน์ว่าไม่มีการเผา และคะแนนต่ำไม่ใช่การรับรองความปลอดภัย ใช้ประกอบการตรวจภาคสนาม

ทะเบียนจังหวัดรองรับ 77 จังหวัด แต่ package มีข้อมูลจริงเฉพาะจังหวัดเดิม ขอบเขตต้องเป็น GeoJSON WGS84 Longitude/Latitude; ไม่รองรับการอ่าน Shapefile/KML ในหน้า Dashboard โดยตรง

คู่มือ PDF และ HTML รุ่นก่อนหน้าเป็นเอกสารประวัติ ไม่ควรนำยอดหรือคำอธิบายสูตรในเอกสารเก่ามาแทนข้อมูล/สูตร runtime รุ่นนี้
